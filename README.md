# Audio Compression Visualizer — Portable Builds

This project preserves the approved waveform and analog controls. No application installation is required on the target computer.

## Get portable builds via GitHub Actions
1. Create a GitHub repository and upload **all** contents of this folder, including `.github/workflows/build.yml` (hidden `.github` folder).
2. Open **Actions → Build portable Windows and macOS apps → Run workflow**.
3. After the workflow finishes, download the three artifacts:
   - **Windows-Portable-EXE**: extract the artifact ZIP and run the `.exe` directly.
   - **macOS-arm-APP**: extract the artifact ZIP, then extract the packaged app ZIP and launch the `.app` on Apple Silicon.
   - **macOS-intel-APP**: same for Intel Macs.

## Build locally (developer machine only)
Requires Node.js 22+ and Internet access for npm dependencies.
- Windows: `npm install` then `npm run build:win`
- Mac Apple Silicon: `npm install` then `npm run build:mac:arm`
- Mac Intel: `npm install` then `npm run build:mac:intel`

## Important
- **The target machine needs no Node.js or Electron installation.** Electron is bundled inside the generated portable app.
- The builds are **unsigned**. Windows SmartScreen and macOS Gatekeeper may warn or block launch; for reliable distribution, sign and notarize the apps.
- macOS `.app` is a folder-based application (the ZIP is for delivery, not an installer).
- This source ZIP is **not itself a compiled executable**. The binaries must be generated by the build workflow.
- `index.html` also works offline in a browser as a quick preview.
